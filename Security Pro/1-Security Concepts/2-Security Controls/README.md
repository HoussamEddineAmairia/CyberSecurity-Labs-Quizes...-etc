> A structured practice assessment focused on **Security Control Classifications** (Technical, Operational, Managerial, Physical) and **Control Functional Types** (Preventative, Detective, Corrective, Deterrent, Directive, Compensating).

---

## 📌 Executive Summary

This assessment evaluates scenario-based decision-making for network administrators, security operation managers, and Chief Security Officers (CSOs) in implementing and classifying security controls.

### 🎯 Key Learning Objectives
- **Control Categories**: Technical, Operational, Managerial, and Physical controls.
- **Functional Classifications**: Preventative, Detective, Corrective, Deterrent, Directive, and Compensating controls.
- **Implementation Scenarios**: Web filtering, server room isolation, physical security devices, and policy enforcement.

---

## 📝 Practice Quiz & Breakdown

<details open>
<summary><b>Question 1: Restricting Web Access & Malware Protection</b></summary>

> **Scenario:** Employees are accessing unmonitored streaming websites. What type of control can a network administrator implement to block these unapproved sites automatically?

* [x] ✅ **A. Technical control** *(Correct)*
* [ ] **B.** Corrective control
* [ ] **C.** Detective control
* [ ] **D.** Operational control

---
#### 💡 Explanation
**Technical controls** use software or hardware mechanisms (like URL filters, firewalls, and proxy systems) to automatically enforce rules and block unapproved network traffic.
</details>

---

<details open>
<summary><b>Question 2: Identifying Preventative Control Appliances</b></summary>

> **Scenario:** Which of the following is a primary example of a **preventative** security control mechanism?

* [x] ✅ **A. An advanced network appliance** *(Correct)*
* [ ] **B.** Network monitoring applications
* [ ] **C.** Intrusion detection systems
* [ ] **D.** Real-time monitoring alerts

---
#### 💡 Explanation
An **advanced network appliance** (e.g., Adaptive Security Appliance / Firewall / IPS) actively blocks unauthorized traffic before it enters the network, functioning as a preventative control. Options B, C, and D are detective controls.
</details>

---

<details open>
<summary><b>Question 3: Physical Isolation of Server Equipment</b></summary>

> **Scenario:** An employee accidentally unplugged a server power cable while grabbing office supplies from a nearby shelf. What security control was lacking?

* [x] ✅ **A. Physical control** *(Correct)*
* [ ] **B.** Operational control
* [ ] **C.** Technical control
* [ ] **D.** Managerial control

---
#### 💡 Explanation
**Physical controls** manage tangibles like server room locks, barriers, cages, and access gates to prevent unauthorized physical access or accidental disruption to critical hardware.
</details>

---

<details open>
<summary><b>Question 4: Enforcing Acceptable Use Policies</b></summary>

> **Scenario:** An Acceptable Use Policy (AUP) mandates encrypting confidential data in transit and using secure email when interacting with vendors. How is this AUP classified?

* [ ] **A.** Managerial
* [x] ✅ **B. Operational control** *(Correct)*
* [ ] **C.** Preventive
* [ ] **D.** Technical

---
#### 💡 Explanation
**Operational controls** focus on day-to-day procedures and responsibilities carried out by people (e.g., adherence to operational policies and user protocols).
</details>

---

<details open>
<summary><b>Question 5: Strategic Security Governance Tools</b></summary>

> **Scenario:** Which type of control leverages management techniques, administrative policies, Disaster Recovery Plans (DRPs), and Business Continuity Plans (BCPs)?

* [x] ✅ **A. Managerial control** *(Correct)*
* [ ] **B.** Preventative
* [ ] **C.** Technical
* [ ] **D.** Operational

---
#### 💡 Explanation
**Managerial controls** (administrative controls) cover strategic oversight, governance, risk management frameworks, security policies, and high-level continuity planning.
</details>

---

<details open>
<summary><b>Question 6: Directing Employee Behavior</b></summary>

> **Scenario:** A Security Operations Manager wants to implement a **directive operational control** to enhance overall security behavior. Which measure fits this criteria?

* [ ] **A.** Firewall to block unauthorized network traffic
* [ ] **B.** Regular vulnerability assessments using automated tools
* [x] ✅ **C. User awareness and training programs** *(Correct)*
* [ ] **D.** Surveillance cameras installed around the premises

---
#### 💡 Explanation
**Directive controls** are designed to instruct or guide human behavior toward compliance with security goals. User awareness and training programs explicitly direct employees on expected behaviors.
</details>

---

<details open>
<summary><b>Question 7: Discouraging Threat Actors</b></summary>

> **Scenario:** Which control type is specifically designed to discourage malicious actors from attempting to breach a network or facility?

* [ ] **A.** Physical
* [x] ✅ **B. Deterrent control** *(Correct)*
* [ ] **C.** Preventative
* [ ] **D.** Detective

---
#### 💡 Explanation
**Deterrent controls** warn or discourage potential attackers before an attempt occurs (e.g., warning signs, visible cameras, guards, and strict penalty policies).
</details>

---

<details open>
<summary><b>Question 8: Detecting Physical Security Events</b></summary>

> **Scenario:** A Chief Security Officer (CSO) wants to add **detective** security controls. Which measure best fulfills this requirement?

* [x] ✅ **A. Installation of surveillance camera** *(Correct)*
* [ ] **B.** Performing regular system backups
* [ ] **C.** Implementation of biometric authentication systems
* [ ] **D.** Enforcement of access control mechanisms

---
#### 💡 Explanation
**Surveillance cameras** monitor and record activities, serving as detective controls that enable teams to discover and analyze incidents during or after they occur. Biometrics and access controls are preventative.
</details>

---

<details open>
<summary><b>Question 9: Remediating Incident Root Causes</b></summary>

> **Scenario:** Following a server outage, a company moved its office supplies out of the server space and implemented a new access restriction system. What category best describes this implementation?

* [ ] **A.** Operational
* [ ] **B.** Detective
* [x] ✅ **C. Corrective control** *(Correct)*
* [ ] **D.** Preventive

---
#### 💡 Explanation
**Corrective controls** are deployed after an incident occurs to fix the root vulnerability, mitigate damage, and prevent the exact incident from repeating.
</details>

---

<details open>
<summary><b>Question 10: Defining Alternate Control Solutions</b></summary>

> **Scenario:** Which statement best describes the purpose of a **compensating control**?

* [ ] **A.** Monitors network activity and informs the security team of a potential security event
* [x] ✅ **B. Partial control solution that is implemented when a control cannot fully meet a requirement** *(Correct)*
* [ ] **C.** Attempts to fix any controls that aren't working properly
* [ ] **D.** Discourages malicious actors from attempting to breach a network

---
#### 💡 Explanation
**Compensating controls** serve as alternative or temporary mechanisms put in place to satisfy a security requirement when a primary control cannot be deployed due to technical or financial constraints.
</details>
